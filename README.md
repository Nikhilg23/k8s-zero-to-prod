# Kubernetes Zero to Production 🚀

Hands-on Kubernetes learning repository focused on **real-world concepts**, not just YAML files.

## 📌 What this repo is about
This repository tracks my Kubernetes learning journey from **basics to production-ready patterns**.  
All examples are tested using `kubectl` and follow practical DevOps workflows.

## 🧱 What I have covered
- Pods and Pod lifecycle
- Deployments and scaling
- Services (ClusterIP)
- Labels and selectors
- Stable networking for dynamic Pods

## 📂 Repository structure
Each folder represents a **learning milestone**:


- Every change is created in a **separate Git branch**
- Changes are merged via **Pull Requests**
- This mirrors real-world DevOps and team workflows

## 🎯 Goal
To build a **strong Kubernetes foundation** by understanding how things actually work inside the cluster — not just by writing manifests.
